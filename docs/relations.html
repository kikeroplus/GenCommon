生成の相関図

J-Rate・PromptWordCrafter・ImageMimicArt 共通。接続先・読み取り・エンハンサー・プロンプト・ベースプロンプトなどが、どうつながって ComfyUI に送られるか。

1. プロンプトが送られるまで

共有の設定 (どのアプリで変えても 3 つに効く) いつも通る段 選んだときだけ通る段
  1. 読み取り (J-Rate・ImageMimicArt): 読み取りプリセットを選ぶと、元画像を LLM に送って説明プロンプトを作り、画像と同じ名前の .txt に書く。読み取り済みの画像は .txt をそのまま使う (「読み取り済みでも読み直す」で読み直す)。同じ画像を何回ぶん頼んでも読み取りは 1 回。
  2. 組み立て (J-Rate): 入力に {caption} があればそこに説明を入れ、なければ「説明 + 改行 + 入力」。入力が空なら説明だけ。読み取りなしなら {caption} は空になる。
  3. エンハンサー: 選んでいれば、エンハンサーの雛形の {prompt} に 2 の結果を入れて LLM に送り、返ってきた文 (盛った本文) に差し替える。
  4. ベースプロンプト: 生成の画面のチェックがオンなら、ワークフローが動画用なら動画用、画像用なら画像用のベースプロンプトを、改行をはさんで最後に付ける。
  5. 入れ先: ワークフローの文字列に {prompt} の目印があればそこを置き換える。なければ Positive / User Prompt のノード、なければ CLIPTextEncode。タイトルに Negative とあるノードと、実際には使われない側 (Switch など) には入れない。
  6. 生成: 接続先の ComfyUI に送る。ジョブは「読み取り → 盛る → ComfyUI」の順に進み、一時停止してから続けても、済んだ段はやり直さない。

共有の一覧を「上へ / 下へ」で並べ替えると、ほかのアプリの選んでいる番号も合わせて直る。

3. セットが覚えるもの (アプリごと)

項目覚え方
接続先・ワークフローURL・ファイルの場所
プロンプト・秒数・プロンプトのプリセットそのときの値
読み取りプリセット・読み取り済みでも読み直す名前とチェック。名前が共有の一覧になければ「なし」にして知らせる
エンハンサー名前。共有の一覧になければ「なし」にして知らせる

セットは名前で共有の設定を指すだけなので、共有の読み取りプリセットやエンハンサーの中身を直すと、それを指すすべてのセットに効く。

5. 生成の記録に残るもの

接続先・ワークフロー・入力したプロンプト・ベースプロンプト・秒数に加えて、読み取りプリセット、送った時点の説明、エンハンサー、盛った本文。「生成時の設定」で見られ、記録から同じ設定で生成し直せる (読み取りとエンハンサーは名前で選び直す)。
