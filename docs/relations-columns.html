生成の相関図 (設定・処理・出力)

J-Rate・PromptWordCrafter・ImageMimicArt 共通。左がユーザーが設定する項目、真ん中が上から順に進む処理、右が出来るもの。

共有の設定 (どのアプリで変えても 3 つに効く) アプリごと・その場で決めるもの 選んだときだけ通る処理 出来るもの

処理の補足

  1. 読み取り (J-Rate・ImageMimicArt): 読み取りプリセットを選んだときだけ。読み取り済みの画像は .txt をそのまま使い、「読み取り済みでも読み直す」なら読み直す。同じ画像を何回ぶん頼んでも読み取りは 1 回。
  2. 組み立て (J-Rate): 入力に {caption} があればそこに説明、なければ「説明 + 改行 + 入力」。入力が空なら説明だけ。PromptWordCrafter は編集欄の本文、ImageMimicArt は説明プロンプトがそのまま本文になる。
  3. エンハンサー: 選んだときだけ。「なし」なら素通り。
  4. ベースプロンプト: 「付ける」がオンのときだけ。ワークフローが動画用なら動画用、画像用なら画像用。
  5. ワークフローに入れる: {prompt} の目印があればそこ、なければ Positive / User Prompt のノード、なければ CLIPTextEncode。Negative と、実際に使われない側には入れない。
  6. 生成: 接続先の ComfyUI へ。一時停止してから続けても、済んだ処理はやり直さない。

セットは接続先・ワークフロー・プロンプト・秒数・読み取りプリセット (名前)・読み直すか・エンハンサー (名前) を覚える (アプリごと)。名前が共有の一覧になければ「なし」になる。もう 1 つの図: relations.html
